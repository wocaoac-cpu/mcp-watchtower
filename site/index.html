HEALTH CHECKS FOR THE MCP ECOSYSTEM

Don't install a dead MCP server.

Third-party audits found roughly half of public MCP servers abandoned — yet no registry shows you a pulse. Watchtower scans the ecosystem continuously and scores every server: ALIVE, FADING, or DEAD.

Methodology

  • Push recency — up to 70 pts. The dominant death signal: audit medians show dead servers sit ~142 days since last commit. ≤14d = 70, decaying to 2 past a year.
  • Community confidence — up to 15 pts. Log-scaled stars. Popularity ≠ health, so it can never rescue a stale repo.
  • Maintenance hygiene — up to 15 pts. License present, issues enabled, description set, not a fork, issue backlog under control.
  • Archived → 3. Repository deleted → GONE.
  • Verdicts: ALIVE ≥ 70 · FADING 40–69 · DEAD < 40. Thresholds are public and debatable — open an issue.
